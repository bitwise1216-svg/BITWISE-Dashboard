# BITWISE &mdash; Executive Admin Dashboard &amp; CMS

> Dedicated Command Center, Telemetry Analytics, Inquiries Inbox, and Content Management System for [bitwise. studio](https://github.com/bitwise1216-svg/BITWISE).

---

## 🚀 Features

- **Real-Time Visitor Analytics**:
  - Live KPI stats: Total Pageviews, Unique Visitors, Avg. Engagement Duration, Conversion Rate.
  - Interactive SVG Traffic Chart (daily trend).
  - Platform Breakdown: Desktop vs Mobile vs Tablet.
  - Traffic Channel Attribution: Direct, Google Search, Instagram, X/Twitter, LinkedIn.
  - Live Visitor Log table with device, OS, browser, and landing page.

- **Inquiries & Leads Inbox ("Get in Touch")**:
  - Automatically captures form submissions from the live portfolio website.
  - Filter by status: All, Unread, Replied, Archived.
  - Direct 1-Click "Reply via Email" generator (`mailto:` with pre-filled subject and context).
  - Export all client leads to CSV.

- **Showcase & Media Manager**:
  - Curate the photography showcase gallery.
  - **Replace Photo**: Pick any image from your computer to swap in place.
  - **Upload New Photo**: Add new photography cards.
  - **Delete Photo**: Remove photos from the showcase.
  - **Auto-Optimization Engine**: Built-in HTML5 Canvas optimizer automatically formats raw camera exports to high-DPI 2560px / JPEG 85%, ensuring rapid load times and completely eliminating Git 408 timeout errors.

- **Website Text & Copy CMS**:
  - Edit Hero headlines, subtexts, CTA button labels.
  - Edit About / Philosophy studio manifesto and statistics.
  - Edit Contact details: Email, Phone, Office Address, and Footer notice.

- **Live Website Viewport**:
  - Embedded split-view preview of the live site.

- **One-Click Publishing to GitHub**:
  - Directly commits and pushes showcase changes, manifest updates, and text edits to the `bitwise1216-svg/BITWISE` repository on GitHub.

---

## 🛠️ How to Run Locally

Simply double-click `index.html` or serve with any static server:

```powershell
# Using Python
python -m http.server 8080

# Or using npx serve
npx serve .
```

Then open `http://localhost:8080` in your browser.
